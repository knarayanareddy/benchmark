Key Fixes & Logic Enhancements Applied

1. In-Page Persona Picking

Added a dedicated, interactive PersonaSelector directly in My Space (/me), Roundtable (/risks/[id]), Pulse (/pulse), and Question Cards (/q/[id]). Users can now pick any persona with 1 click right on the page without depending on the top bar or getting kicked to Pulse.

2. Preserved Route Context on Switch

Removed the hard-coded redirect to /pulse in PersonaSwitcher. When switching personas while reading a Roundtable or inside My Space, the app now stays on the current page and refreshes in place with the newly selected identity.

3. Database Fallback & Cookie Sync

Fixed the bug where newly created profiles from Pulse/Join failed to resolve due to React server-cache lookup misses. currentExpert() and /api/session now query the PostgreSQL table directly if a newly created expert isn't in memory yet, guaranteeing 100% persistence.

4. Full Profile Editing in My Space

Expanded ProfileForm and /api/profile to allow editing and saving Real Name, Organisation, Role Type, Countries Covered, and Themes alongside anonymity levels and weekly caps.
